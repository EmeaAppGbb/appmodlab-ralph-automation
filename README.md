# Ralph Automation

This lab demonstrates configuring Ralph for autonomous backlog processing in the WeatherLens dashboard project.

## Structure
- `frontend/` - React weather dashboard
- `backend/` - Node.js API server
- `.squad/agents/ralph/` - Ralph configuration
- `docs/BACKLOG.md` - Pre-loaded backlog items

See [APPMODLAB.md](APPMODLAB.md) for complete lab documentation.
